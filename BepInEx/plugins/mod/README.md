
# MoreGuns

Adds more guns

# The Guns
- Holepuncher: A powerful shotgun based off the scattergun. Extremely deadly at close ranges.
- Hotswap: A 2-in-1 rifle featuring a fully automatic bullpup mode and a lethal penetrating shot.
- Viper: A unique weapon which inflicts its targets with an armor shreading causatic effect, dealing damage over time.
- Rocket Launcher: A single shot rocket launcher which annihilates groups of enemies.
- Grenade Launcher: A trusty grenade launcher capable of clearing swarms with ease.
- Vampire: A special shotgun capable of healing the user, allowing them to survive impossible scenarios.
- Spongebath: A defensive gun with incredible crowd control abilities thanks to its C-Foam properties.
- Eruptor: An explosive precision rifle which can decimate swarms and tanks alike.
- Draco: A hard hitting pistol-rifle hybrid firing hollow point rounds. 
- Bloodthirst: A double edged sword of a machine gun which drains your health for firing, but heals upon getting a kill.
- Whisper: A compact silenced pistol capable of quickly removing sleeping enemies, perfect for missions where stealth is a priority.
- Artificer: An 8 round compressed air shooter which automatically reloads without needing ammopacks.
- The Wall: A machine gun which shreds enemies with its ramping fire rate and massive magazine.
- Accumulator: A unique light rifle which gains increased damage over the course the expedition.
- Tenderizer: A slug shotgun which inflicts a powerful debuff and can shred bosses.
- First Responder: A stim pistol which allows the user to heal themself or their allies.
- Inferno: A short range flamethrower which leaves residual flames that set enemies ablaze. 
- Blitzer: A chain shotgun which chains salvos by hitting enemies.
- Kraken: A machine gun which fires homing bullets like the boss of the same name. 
- Nightfall: A mid-range rifle which gains a powerful buff through combat.
- Detonator: A shotgun pistol which causes enemies to explode upon death.
- Vengeance: A powerful shotgun which deals more damage the lower health you have.
