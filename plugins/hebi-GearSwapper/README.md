# GearSwapper

A simple mod that allows players to swap between the burst sentry, sniper sentry, bio-tracker, c-foam launcher, and the mine deployer while in an expedition. I made this mod for some friends, so its functionality is only intended as such.

Keybinds:  
F1 - Biotracker  
F2 - C-Foam  
F3 - Mine Deployer  
F4 - Burst Sentry  
F5 - Sniper Sentry  
F6 - Shotgun Sentry  
F7 - HEL Auto Sentry
